# Ethara.ai Task Manager

A role-based Task Management System built using Spring Boot, Thymeleaf, Spring Security, and H2 Database.

## Features

- User Authentication & Authorization
- Role-based access (Admin, Manager, Member)
- Task creation and management
- Team management
- Dashboard analytics
- Responsive UI design

## Technologies Used

- Java 17
- Spring Boot
- Spring Security
- Thymeleaf
- Maven
- H2 Database

## Run Locally

```bash
mvn spring-boot:run
