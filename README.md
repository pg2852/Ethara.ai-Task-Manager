# Ethara.ai Task Manager

## Project Description
Ethara.ai Task Manager is a full-stack web application built for managing teams and tasks inside an organization. Users can create teams, assign tasks, track progress, and manage work using role-based access control.

The system helps companies organize projects and improve team collaboration by allowing different users to perform actions based on their roles.

## Features

### User Authentication
- User signup and login system
- Secure password encryption using Spring Security
- Role-based access control

### Role Management
- Admin can manage users and teams
- Manager can create and assign tasks
- Members can view assigned tasks and update task progress

### Team Management
- Create teams
- View team information
- Manage team members

### Task Management
- Create tasks
- Assign tasks to team members
- Set task priority
- Update task status
- Track progress

### Dashboard
- Total task count
- To Do tasks
- In Progress tasks
- Completed tasks
- Team information overview
